# Bookmark rules

- Keep all bookmarks in the root `README.md`. Do not add other README files.
- Use the `add-bookmark` skill when adding or updating bookmarks.
- Group tools by what they do, not by company or popularity.
- Reuse categories. Add a new one only when no existing category fits.
- List each tool once, with its direct project link and a short, plain-language description.
- Keep entries alphabetical within each category.
- Do not commit or push unless asked.
